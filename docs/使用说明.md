# 使用说明

本文档介绍学生成绩管理系统两套版本的使用方法、数据规则与常见问题。

## 一、Python 命令行版

### 启动

在仓库根目录执行：

```bash
python src/python/student_grade_management.py
```

### 功能菜单

| 序号 | 功能 | 说明 |
| --- | --- | --- |
| 1 | 添加学生 | 依次输入学号、姓名、成绩；学号不可重复 |
| 2 | 查询学生 | 输入学号，显示该学生的学号、姓名、成绩 |
| 3 | 修改成绩 | 输入学号后输入新成绩 |
| 4 | 删除学生 | 输入学号，直接删除（无二次确认） |
| 5 | 显示全部 | 以表格形式输出全部学生 |
| 6 | 保存数据 | 将当前数据写入 `score.txt` |
| 0 | 退出系统 | 结束程序 |

### 数据文件

- 程序通过 `score.txt` 读取与保存数据，路径相对于**运行程序时的工作目录**。
- 文件格式为每行 `学号,姓名,成绩`，使用英文逗号分隔，编码为 UTF-8。
- 若文件不存在，程序会以空数据启动，不会报错。
- 建议先在仓库根目录复制示例数据：

```bash
cp data/score.example.txt score.txt
```

### 校验规则

- 学号重复：提示「该学号已存在！」，不会写入。
- 成绩不是数字：提示「成绩必须输入数字！」，不会写入。
- 修改 / 删除时学号不存在：提示「没有找到该学生！」。

## 二、Web 可视化版

### 启动

双击 `index.html`，或将其拖入浏览器窗口即可，无需联网。

### 主要操作

- **添加学生**：点击「添加学生」，填写学号、姓名、成绩后确认；表单会校验学号唯一与成绩格式。
- **查询学生**：在搜索框输入学号或姓名，列表实时过滤；无匹配时显示「没有找到该学生！」。
- **修改成绩**：点击对应行的「修改」，输入新成绩并保存。
- **删除学生**：点击对应行的「删除」，在确认弹窗中确认后删除。
- **查看完整名单**：点击顶部「学生总数」卡片，弹出学生名单；可通过右上角 ✕、「收起名单」、点击遮罩或按 Esc 关闭。
- **保存数据**：每次增删改会自动写入浏览器本地存储，也可点击「保存数据」手动保存。

### 数据存储

- 数据保存在浏览器 `localStorage` 的 `studentGradeData.v1` 键中。
- 更换浏览器、使用无痕模式或清除站点数据后，数据不会保留。
- Web 版与 Python 版的数据文件互不相通，如需迁移可手动录入。

### 可视化内容

- 成绩分布柱状图：按 `0-59`、`60-69`、`70-79`、`80-89`、`90-100` 分数段统计人数。
- 等级分布：优秀、良好、中等、及格、不及格人数及占比，并显示及格率环形图。
- 成绩排名：按成绩从高到低排列，同分同名次，前三名高亮显示。

## 三、成绩等级

| 等级 | 分数区间 |
| --- | --- |
| 优秀 | ≥ 90 |
| 良好 | 80 ~ 89.99 |
| 中等 | 70 ~ 79.99 |
| 及格 | 60 ~ 69.99 |
| 不及格 | < 60 |

## 四、常见问题

**Q：Python 版运行后找不到 `score.txt`？**

A：程序按运行目录读写数据。请确认执行命令时位于仓库根目录，或在程序所在目录运行。

**Q：Web 版刷新后数据还在吗？**

A：在，数据保存在浏览器本地存储中。清除浏览器数据后会丢失。

**Q：学号可以输入中文或空格吗？**

A：原程序未限制学号格式，但会去除首尾空格后再校验唯一性，建议使用数字或字母组合。

**Q：成绩可以输入小数或负数吗？**

A：可以，成绩按浮点数处理，与 Python 版 `float()` 规则一致。
